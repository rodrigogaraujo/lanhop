# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, criticise code and ideas and not people, and do not harass anyone.

## Scope

It applies to every project space: issues, pull requests, discussions and any other place where someone represents the project.

## Reporting

Report unacceptable behaviour to **rodrigoaraujo990@gmail.com**. Reports are read by the maintainer and kept confidential.

## Enforcement

The maintainer may remove, edit or reject comments, commits, issues and pull requests that break this code, and may ban a contributor temporarily or permanently. The enforcement guidelines of the Contributor Covenant apply.
